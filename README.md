# WellTrack BI
Business Intelligence & Analytics Platform for Wellness Businesses.

## Requirements
Java 21+, MySQL 8+

## Setup
1. Import database: mysql -u root -p welltrack_db < welltrack_db.sql
2. Update credentials in src/main/resources/application.properties
3. Run: ./mvnw spring-boot:run
4. Open: http://localhost:8080/login.html
